## TLS strategy

| Option | Description | Selected |
|--------|-------------|----------|
| Self-signed via Traefik default cert | No extra tooling; browser shows a warning | ✓ |
| mkcert local trusted CA | No browser warning, but requires extra local tooling/setup | |
| Plain HTTP | Simplest, but violates Keycloak's exact `https://` redirect URI requirement | |

**Agent's choice:** Self-signed via Traefik default cert — cheapest path that still satisfies the `https://` scheme Keycloak requires; a real ACME certificate cannot be issued for `example.com` anyway.
**Notes:** mkcert noted as optional future polish, not required for this phase.
