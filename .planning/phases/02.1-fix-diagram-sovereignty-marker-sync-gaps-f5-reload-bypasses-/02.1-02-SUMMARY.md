# Phase 02.1 Plan 02: Live-Reposition Sovereignty Marker Ellipses During Drag Summary

**Sovereignty marker fill/ring ellipses now live-reposition in place on every `onChange` event (including mid-drag), by recomputing the same top-right-anchor geometry `createMarkerEllipses` uses and mutating the existing ellipse pair's position/version metadata — preserving element identity and incurring zero extra work for elements without markers.**

## Accomplishments

- Added `repositionMarkerEllipses(mainElement, fillEllipse, ringEllipse)` to `sovereigntyMarkers.ts`: recomputes `fillX`/`fillY`/`ringX`/`ringY` using the exact same `fillSize = 10`/`ringSize = 18` top-right-anchor formula as `createMarkerEllipses`, returning mutated copies (same `id`, bumped `version`/`versionNonce`/`updated`) or `null` when the position is unchanged.
- Added `repositionAllMarkerEllipses(elements)` to the same file: builds a one-pass `Map` of existing fill/ring pairs keyed by `customData.mainElementId`, repositions only main elements that have a *complete* pair (D-04), and returns the original `elements` reference with `changed: false` when nothing needed repositioning (no extra allocation for the common no-markers case) or a new array with the repositioned pairs substituted by `id` otherwise.
- Wired `repositionAllMarkerEllipses` into `ExcalidrawWrapper.tsx`'s `handleChange`: called on every `onChange` immediately after the existing `suppressOnChangeRef` early-exit guard; when `changed` is `true`, sets `suppressOnChangeRef.current = true` and calls `apiRef.current?.updateScene({ elements: repositionedElements }, false)` (the same `{ elements }, false` no-history-entry shape already used by `DiagramLibrarySidebar.tsx`/`addRelatedElementsService.ts`), then uses the repositioned elements array for the subsequent forwarded `onChange`/`broadcastSceneUpdate` calls in the same invocation so collaborators and the unsaved-changes tracker see corrected positions immediately.
- `apiRef` added to `handleChange`'s `useCallback` dependency array; no other guard chain, broadcast, or suppress logic altered — `createMarkerEllipses`/`applySovereigntyMarkers`/`fetchSovereigntyMarkersForDiagram`/`syncSovereigntyMarkers` remain completely unchanged (sync-time path untouched, per plan scope).
