## Live-drag mechanism

| Option | Description | Selected |
|--------|-------------|----------|
| Live reposition on every onChange | Ellipses track the element in real time during the drag — smoothest UX, recomputes on every onChange event (fires frequently already). | ✓ |
| Snap into place after drag ends | Ellipses stay static during the drag, jump to correct position on release (pointer-up) — cheaper, small visual lag only mid-drag. | |

**User's choice:** Live reposition on every onChange
**Notes:** Marker ellipses are only grouped (groupIds), not natively bound (containerId is text-only in Excalidraw), so they don't follow a dragged main element.
